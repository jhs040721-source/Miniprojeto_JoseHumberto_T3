# Mini-Projeto — Análise da Base Varejo

Mini-projeto desenvolvido por **José Humberto de Souza**, da turma **T3 — Visualização de Dados e Business Intelligence**.

## Objetivo

Importar, diagnosticar, limpar e analisar uma base de dados de varejo utilizando Python, pandas e Google Colab.

## Principais resultados

- Base original: 830.000 registros e 14 colunas.
- Base limpa: 733.447 registros e 10 colunas.
- Duplicatas removidas: 96.553.
- Gênero feminino: 52,14% das compras.
- Categoria Alimentos: 52,38% das compras.
- Segmento B: 63,88% das compras.
- Produto mais comprado: Presunto Cozido.
- Classe A da análise ABC: 91 produtos e 80,59% das compras.

## Como executar

1. Abra o arquivo `Miniprojeto_Varejo_JoseHumberto.ipynb` no Google Colab.
2. Clique em **Ambiente de execução**.
3. Selecione **Executar tudo**.
4. Aguarde a importação automática da base do Kaggle e a conclusão das análises.

## Arquivos

- `Miniprojeto_Varejo_JoseHumberto.ipynb`: código completo e comentado.
- `README_JoseHumberto_T3.md`: documentação detalhada.
- `Varejo_limpo.csv.zip`: base limpa compactada, contendo o arquivo `Varejo_limpo.csv`.
